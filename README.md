# 求真分析（Fact-Based Analysis）

一个用于分析不同上市公司的可复用研究技能。输入股票代码或公司名称，即可按行业与商业模式适配分析口径，核对证据、财务质量、资本回报、估值预期和主要反证，并在条件允许时生成高可读性 HTML 报告。

## 安装

### Codex

在终端运行：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/JohnWish1590/Fact-Based-Analysis.git ~/.codex/skills/stock-truth-analysis
```

重新打开 Codex 后，技能可按相关请求自动触发，也可在提示中显式写：

```text
$stock-truth-analysis 求真分析 000792 盐湖股份
```

更新技能：

```bash
git -C ~/.codex/skills/stock-truth-analysis pull
```

### ChatGPT 或其他支持 Agent Skills 的产品

下载本仓库，将根目录作为技能文件夹导入。技能入口文件为 `SKILL.md`，界面元数据位于 `agents/openai.yaml`。不同产品的导入入口和技能目录可能不同，请按对应产品的 Skills/技能导入界面操作。

## 技能分析什么

技能以证据、口径一致和可证伪为原则，适用于 A 股、港股和美股的不同上市公司，不依赖某一家公司的专属资料。

- **行业适配**：先判断行业、商业模式、生命周期、资本强度及收入确认方式，再选指标；不机械套用单一估值或财务模板。
- **统一财务口径**：核对报告期、币种、单位、合并范围、归母口径、一次性项目、现金与非现金项目；自行调整时列出公式、假设和来源。
- **证据等级**：对关键论点区分 FACT（事实）、CALCULATION（计算）、INFERENCE（推断）和 UNCERTAINTY（不确定性）。
- **改善代价**：检查增长或利润率改善是否以降价、投入增加、资本开支、营运资金、杠杆、并购、稀释、一次性收益或风险转移为代价。
- **背离与反证**：寻找利润与现金流、订单与收入、存货与需求、管理层表述与披露之间的背离，并列出最强反方解释。
- **资本回报**：在适用时分析 ROE、ROIC 与 Incremental ROIC；说明口径与并购、周期等干扰。
- **估值与预期**：选择适合商业模式的估值方法，进行 Reverse Valuation（反推当前价格隐含的增长和回报预期）与 Expectation Gap（市场预期、兑现条件、潜在差异）。
- **持续搜索与熔断**：重要数据缺失时继续查公告、年报附注、交易所及监管披露；若关键数据仍不足以支持核心计算，就停止给出依赖它的确定结论或精确估值，并说明缺口和影响。
- **明确结论**：总结支持证据、反证、不确定性、观察指标和 Kill Criteria（推翻核心判断的条件）。需要时说明行业周期；用户要求时补充日线和周线判断。
- **自然中文与 HTML**：默认使用简体中文、连续易读的自然段；系统性研究尽可能同时提供适合桌面和手机阅读的高可读性 HTML 报告。

## 使用示例

```text
$stock-truth-analysis 求真分析 02617.HK，核查临床数据、财务状况和估值
```

```text
$stock-truth-analysis 分析这家公司利润增长是否有现金流和资本回报支撑
```

```text
$stock-truth-analysis 从当前市值反推市场隐含预期，并列出能推翻投资逻辑的事实
```

本技能提供研究流程，不替代实时核实。分析中的市场价格和披露会随时间变化，每次使用都应重新检索并注明数据日期和来源。
